# Oppimispäiväkirja: Hajautettu git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?__

Etärepositorion käyttö ja GitHubiin pushaaminen olivat melko helppoja. Vaikeampaa oli aluksi ymmärtää fetch-, pull- ja merge-komentojen erot sekä se, miten paikallinen ja etärepositorion haara liittyvät toisiinsa. Opin parhaiten tekemällä muutoksia sekä paikallisesti että GitHubissa ja seuraamalla git status -komennolla, mitä tapahtui.


## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git remote -v | Näyttää etärepositoriot |
| git push | Vie paikalliset muutokset etärepositorioon |
| git fetch | Hakee muutokset etärepositoriosta yhdistämättä niitä |
| git pull | Hakee ja yhdistää etärepositorion muutokset |
| git merge | Yhdistää haaran muutokset nykyiseen haaraan |
| git clone | Kloonaa etärepositorion omalle koneelle |
